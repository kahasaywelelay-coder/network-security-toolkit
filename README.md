# Network Security & Scanning Toolkit

A collection of lightweight Python and Bash utilities built for network reconnaissance, port scanning, host discovery, and vulnerability enumeration.

---

## Repository Structure

```text
network-security-toolkit/
├── socket_scanner.py       # 1. Pure Python socket port scanner
├── nmap_scanner.py         # 2. Port scanner using python-nmap module
├── host_discovery.py       # 4. Host discovery tool (local IP, IP class, and gateway)
├── nmap_nse.sh             # 5. Bash script wrapper for Nmap NSE scripts
└── requirements.txt        # Python package dependencies
