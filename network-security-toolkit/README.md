# Network Security & Scanning Toolkit

A collection of lightweight Python and Bash utilities for network reconnaissance, port scanning, and host discovery.

---

## Prerequisites

* **Python 3.x**
* **Nmap** (must be installed on your system path for the Nmap-dependent scripts to work)
  * *Ubuntu/Debian:* `sudo apt install nmap`
  * *macOS:* `brew install nmap`

Install the required Python packages:
```bash
pip install -r requirements.txt
